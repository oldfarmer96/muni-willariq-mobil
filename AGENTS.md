# Expo HAS CHANGED

Read the exact versioned docs at https://docs.expo.dev/versions/v57.0.0/ before writing any code.

## Package manager

Use pnpm exclusively for this project.

- Use `pnpm install`, `pnpm add`, `pnpm remove`, and `pnpm exec`.
- Install Expo-managed packages with `pnpm exec expo install` so Expo selects compatible versions.
- Do not create or update npm or Yarn lockfiles. `pnpm-lock.yaml` is the source of truth.
